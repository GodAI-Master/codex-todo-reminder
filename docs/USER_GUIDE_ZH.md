# 待办任务使用教程

## 1. 建立适合日常工作的清单

先把任务放进以下节奏：

- **收集箱**：还没安排时间，但不能忘的事。
- **今天**：今天需要推进或已经逾期的事。
- **即将到期**：未来已经排好时间的事项。
- **重复任务**：周报、复盘、备份检查等固定节奏。
- **已完成**：保留成果记录，必要时可以恢复。

顶部输入框适合快速记录。事项需要更多信息时，点击“编辑”，补充备注、时间、提醒和重复规则。

## 2. Vibecoding 场景的推荐用法

一个功能只保留一条“下一步行动”，避免把面板变成需求文档。例如：

- `修复登录态刷新后丢失`
- 备注：`复现路径、相关文件、完成标准`
- 优先级：高
- 到期：今天下班前
- 提醒：到期前 30 分钟

推荐节奏：

1. 灵感先进入收集箱。
2. 开始编码前，只挑 1–3 条放到今天。
3. 完成一个可验证结果就勾掉，不把“继续优化”长期悬空。
4. 每天下班前处理逾期项：完成、改期或删除。
5. 每周建立一条重复任务：“整理本周技术债与下周第一步”。

可以直接让 Codex 操作：

- “新增高优先级待办：修复支付回调重复写入，今天 18:00 到期，提前 30 分钟提醒。”
- “显示今天的所有待办。”
- “把 TODO-0012 稍后 1 小时提醒。”
- “完成 TODO-0012。”

## 3. 日常工作管理

将待办写成动词开头、可以明确完成的事项：

- 好：`向张经理确认最终报价`
- 不够清楚：`报价`

优先级建议：

- **高**：今天不处理会造成明确损失或阻塞他人。
- **中**：重要，但可按计划推进。
- **低**：有价值，时间允许时处理。
- **普通**：仅用于记录和排队。

提醒时间应放在“可以采取行动”的时刻。会议建议提前 10–30 分钟；深度工作建议在计划开始时提醒。

## 4. 重复任务

支持每日、工作日、每周、每月和每年。完成当前一次后，系统会自动生成下一个时间点，不会把整条重复任务永久完成。

适合设置为重复任务的事项：

- 工作日 9:20：确定今日最重要的一件事
- 每周五 16:30：提交周报
- 每月最后一天：整理发票与报销
- 每年固定日期：证件或订阅续期检查

## 5. 通知与稍后提醒

Windows 通知出现后可以：

- **完成**：立即完成当前任务或本次重复任务。
- **10 分钟后**：把本次提醒顺延 10 分钟。
- **1 小时后**：把本次提醒顺延 1 小时。
- 点击通知正文：打开带有待办面板的 Codex。

电脑睡眠或服务短暂退出时，系统会在恢复后补发合理时间范围内错过的提醒，并通过记录避免重复轰炸。

## 6. 数据备份与迁移

进入 **设置与备份**：

- **导出全部待办**：生成可迁移的 JSON 文件。
- **选择导入文件**：先预览数量，再合并导入；已有记录不会被覆盖。
- **立即备份**：生成完整本机数据库备份。
- **恢复**：选择历史备份，后台重启后面板会自动重新连接。

系统每天自动备份一次，并保留最近 14 份自动备份。数据目录为：

```text
%LOCALAPPDATA%\CodexTodoReminder
```
